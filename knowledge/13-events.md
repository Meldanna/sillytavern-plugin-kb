# 事件系统 event_types 用法

## 基本用法

```js
import { eventSource, event_types } from '../../../events.js';

const handler = messageId => { /* ... */ };

eventSource.on(event_types.CHARACTER_MESSAGE_RENDERED, handler);
eventSource.once(event_types.APP_READY, () => initAfterReady());
eventSource.makeLast(event_types.CHARACTER_MESSAGE_RENDERED, handler); // 确保最后执行
eventSource.removeListener(event_types.CHARACTER_MESSAGE_RENDERED, handler);
```

- 注册在扩展模块顶层，**不要**放到 `$(document).ready` 里再注册（可能错过早期事件）。
- 每次注册都要能在禁用/卸载路径上 `removeListener`，否则重建 UI 时会重复触发。
- `makeFirst` / `makeLast` 用于调整与其它扩展的相对顺序，只有确有先后依赖时才用。

## 常用事件的时机

| 事件 | 时机 | 典型用途 |
| --- | --- | --- |
| `APP_READY` | 酒馆初始化完成、可用 | 构建 UI、注册命令 |
| `EXTENSIONS_FIRST_LOAD` / `EXTENSION_SETTINGS_LOADED` / `SETTINGS_LOADED` | 设置数据就绪 | 首次读取配置 |
| `CHAT_CHANGED` / `CHAT_LOADED` | 切换聊天 | 重载按聊天保存的状态 |
| `MESSAGE_SENT` / `MESSAGE_RECEIVED` / `MESSAGE_EDITED` / `MESSAGE_DELETED` | 消息增删改 | 记录、改写、翻译 |
| `CHARACTER_MESSAGE_RENDERED` / `USER_MESSAGE_RENDERED` | DOM 渲染完成 | 对楼层做后处理 |
| `GENERATION_STARTED` / `GENERATION_ENDED` / `GENERATION_STOPPED` | 生成前后 | 加载动画、状态锁 |
| `GENERATE_AFTER_COMBINE_PROMPTS` / `GENERATE_AFTER_DATA` | 提示词组装阶段 | 注入扩展 prompt |
| `WORLD_INFO_ACTIVATED` / `WORLDINFO_UPDATED` / `WORLDINFO_SCAN_DONE` | 世界书扫描 | 读取命中的条目 |
| `PRESET_CHANGED` / `OAI_PRESET_CHANGED_BEFORE` / `_AFTER` | 预设切换 | 预设相关插件 |
| `STREAM_TOKEN_RECEIVED` | 流式增量 token | 边生成边处理 |
| `CHARACTER_EDITED` / `CHARACTER_DELETED` / `GROUP_UPDATED` | 角色/群组变化 | 刷新缓存 |

## 完整清单（1.18.0）

`event_types` 的键名与字符串值并不总是一致（例如 `CHAT_CHANGED: 'chat_id_changed'`、`CHAT_LOADED: 'chatLoaded'`、`CHARACTER_DELETED: 'characterDeleted'`），**必须用常量**而不是自己拼字符串。完整定义以 `public/scripts/events.js` 为准，此处按用途分组列出：

- 生命周期：`APP_INITIALIZED`、`APP_READY`、`EXTRAS_CONNECTED`、`EXTENSIONS_FIRST_LOAD`、`EXTENSION_SETTINGS_LOADED`、`SETTINGS_LOADED`、`SETTINGS_LOADED_BEFORE`、`SETTINGS_LOADED_AFTER`、`SETTINGS_UPDATED`、`MOVABLE_PANELS_RESET`
- 聊天：`CHAT_CHANGED`、`CHAT_LOADED`、`CHAT_CREATED`、`CHAT_DELETED`、`CHAT_RENAMED`、`GROUP_CHAT_CREATED`、`GROUP_CHAT_DELETED`、`MORE_MESSAGES_LOADED`
- 消息：`MESSAGE_SENT`、`MESSAGE_RECEIVED`、`MESSAGE_EDITED`、`MESSAGE_DELETED`、`MESSAGE_UPDATED`、`MESSAGE_SWIPED`、`MESSAGE_SWIPE_DELETED`、`MESSAGE_FILE_EMBEDDED`、`MESSAGE_REASONING_EDITED`、`MESSAGE_REASONING_DELETED`、`USER_MESSAGE_RENDERED`、`CHARACTER_MESSAGE_RENDERED`、`FILE_ATTACHMENT_DELETED`、`MEDIA_ATTACHMENT_DELETED`
- 生成：`GENERATION_AFTER_COMMANDS`、`GENERATION_STARTED`、`GENERATION_STOPPED`、`GENERATION_ENDED`、`GENERATE_BEFORE_COMBINE_PROMPTS`、`GENERATE_AFTER_COMBINE_PROMPTS`、`GENERATE_AFTER_DATA`、`TEXT_COMPLETION_SETTINGS_READY`、`CHAT_COMPLETION_SETTINGS_READY`、`CHAT_COMPLETION_PROMPT_READY`、`STREAM_TOKEN_RECEIVED`（别名 `SMOOTH_STREAM_TOKEN_RECEIVED`，已废弃）、`STREAM_REASONING_DONE`、`IMPERSONATE_READY`、`TOOL_CALLS_PERFORMED`、`TOOL_CALLS_RENDERED`
- 世界书：`WORLDINFO_SETTINGS_UPDATED`、`WORLDINFO_UPDATED`、`WORLDINFO_ENTRIES_LOADED`、`WORLD_INFO_ACTIVATED`、`WORLDINFO_FORCE_ACTIVATE`、`WORLDINFO_SCAN_DONE`
- 角色/群组：`CHARACTER_EDITOR_OPENED`、`CHARACTER_EDITED`、`CHARACTER_PAGE_LOADED`、`CHARACTER_DELETED`、`CHARACTER_DUPLICATED`、`CHARACTER_RENAMED`、`CHARACTER_RENAMED_IN_PAST_CHAT`、`CHARACTER_FIRST_MESSAGE_SELECTED`、`CHARACTER_GROUP_OVERLAY_STATE_CHANGE_BEFORE`、`CHARACTER_GROUP_OVERLAY_STATE_CHANGE_AFTER`、`CHARACTER_MANAGEMENT_DROPDOWN`、`GROUP_UPDATED`、`GROUP_MEMBER_DRAFTED`、`GROUP_WRAPPER_STARTED`、`GROUP_WRAPPER_FINISHED`、`OPEN_CHARACTER_LIBRARY`
- 预设/连接：`PRESET_CHANGED`、`PRESET_DELETED`、`PRESET_RENAMED`、`PRESET_RENAMED_BEFORE`、`OAI_PRESET_CHANGED_BEFORE`、`OAI_PRESET_CHANGED_AFTER`、`OAI_PRESET_EXPORT_READY`、`OAI_PRESET_IMPORT_READY`、`CHATCOMPLETION_SOURCE_CHANGED`、`CHATCOMPLETION_MODEL_CHANGED`、`MAIN_API_CHANGED`、`CONNECTION_PROFILE_LOADED`、`CONNECTION_PROFILE_CREATED`、`CONNECTION_PROFILE_DELETED`、`CONNECTION_PROFILE_UPDATED`、`ONLINE_STATUS_CHANGED`
- 人设/密钥/其它：`PERSONA_CHANGED`、`PERSONA_CREATED`、`PERSONA_UPDATED`、`PERSONA_RENAMED`、`PERSONA_DELETED`、`SECRET_WRITTEN`、`SECRET_DELETED`、`SECRET_ROTATED`、`SECRET_EDITED`、`TTS_JOB_STARTED`、`TTS_AUDIO_READY`、`TTS_JOB_COMPLETE`、`SD_PROMPT_PROCESSING`、`IMAGE_SWIPED`、`FORCE_SET_BACKGROUND`、`ITEMIZED_PROMPTS_LOADED`、`ITEMIZED_PROMPTS_SAVED`、`ITEMIZED_PROMPTS_DELETED`
