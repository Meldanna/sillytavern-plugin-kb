# 扩展 UI、模板与国际化

## 三种常见挂载点

| 位置 | 选择器 / 方式 | 适用 |
| --- | --- | --- |
| 扩展设置抽屉 | 扩展自己的 `settings.html`，通过 `renderExtensionTemplateAsync(name, 'settings')` 渲染后插入 `#extensions_settings2` | 插件配置项 |
| 魔杖菜单（快捷按钮） | 追加到 `#extensionsMenu`，外层按钮在 `#extensionsMenuButton` | 一句话能描述的操作入口 |
| 独立浮层 / 抽屉 | 自行 `append` 到 `body`，用 `position: fixed` + `z-index` | 复杂面板（如预设管理器、楼层改写） |

```js
const html = await SillyTavern.getContext().renderExtensionTemplateAsync('my-plugin', 'settings');
$('#extensions_settings2').append(html);
```

模板文件放在扩展目录下（如 `settings.html`），渲染时默认 **强制消毒 + 强制本地化**（`sanitize = true, localize = true`）。需要插入用户内容时不要绕开消毒。

## 国际化

两种粒度：

1. **DOM 属性**：`<div data-i18n="My Label"></div>`，页面级翻译会自动生效。
2. **JS 字符串**：从 `ctx.t` / `import { t } from '../../../i18n.js'` 取翻译函数，模板字符串写成 `` t`我的文本` ``。

扩展自己的语言包在 `manifest.json` 的 `i18n` 字段声明，运行时由酒馆按当前语言 `fetch` 一个文件并 `addLocaleData()`：

```json
"i18n": { "en": "i18n/en.json", "zh-cn": "i18n/zh-cn.json" }
```

更完整的覆盖（例如需要多语言 + 大量文案）可以在扩展内部再挂一层自己的 i18n 模块，但对外展示优先用酒馆的这套，用户切语言时无需重启。

## 样式约定

- 使用酒馆的 CSS 变量跟随主题色，例如 `var(--SmartThemeBodyColor)`、`var(--SmartThemeBlurTintColor)`、`var(--SmartThemeBorderColor)`，不要在插件里写死前景/背景色，否则亮色主题下不可读。
- 复用现成类名保持观感一致：`text_pole`（输入框）、`menu_button`、`menu_button_icon`、`interactable`、`flex-container`、`wide100p` 等。
- 移动端用 `ctx.isMobile` 判断，并让布局自适应（面板宽度用 `max-width: min(90vw, 720px)` 之类写法）。
- 样式通过 `manifest.json` 的 `css` 字段注入，不要 `document.write` 或注入内联 `<script>`。

## 浮层与拖拽

- 需要可拖动/可缩放的浮层，参考酒馆的浮层约定：`position: fixed` + `pointer-events` 控制，只保留一个顶层容器避免多点重复初始化。
- 与酒馆自带弹窗交互用 `ctx.callGenericPopup(html, ctx.POPUP_TYPE.CONFIRM)`，别自己写 `confirm()`（移动端样式与焦点管理都不同）。

## 避免的写法

- 直接改酒馆核心 DOM 结构（例如把 `#chat` 整个替换）：版本升级必坏。用事件钩子或追加式插入。
- 在插件里 `console.log` 大对象刷屏：用 `ctx.registerDebugFunction` 注册到调试面板。
- 只有中文文案、没有 `t()`：多语言用户在英文界面下会看到中文，审核时会被视为缺项。
